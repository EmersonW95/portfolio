## 👨‍💻 Sobre o projeto

Este projeto é o meu **portfólio pessoal**, desenvolvido com o objetivo de reunir, em um único espaço, informações sobre minha formação acadêmica, projetos, atividades extracurriculares e trajetória na área de tecnologia.

A aplicação foi construída utilizando **Next.js e React**, seguindo uma estrutura baseada no **App Router** e em componentes reutilizáveis.

O projeto também conta com uma página interativa dedicada ao clássico **Jogo da Forca**, desenvolvida para aplicar conceitos de componentes, gerenciamento de estado e interação com o usuário.

### 🎯 Objetivos

- Apresentar minha trajetória acadêmica e profissional;
- Centralizar meus principais projetos;
- Demonstrar conhecimentos em desenvolvimento web;
- Aplicar conceitos de React e Next.js em um projeto real;
- Criar uma aplicação responsiva e organizada;
- Disponibilizar meu portfólio publicamente na web.
